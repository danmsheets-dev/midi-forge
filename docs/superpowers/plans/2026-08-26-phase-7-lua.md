# Phase 7 Lua scripting

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** A sandboxed Lua 5.4 processor that runs on captured MIDI before thru. Scripts can drop, rewrite, or fan out events. The monitor still shows the raw wire. No `io`/`os`/`package`/`debug`.

**Architecture:** New crate `midi-forge-script` depends on `midi-forge-core` + vendored `mlua` (`lua54`). The desktop app owns a `ScriptEngine` on the UI thread (capture already hops off the WinMM callback). Core stays OS-free.

---

## File map

| Path | Responsibility |
|------|----------------|
| `crates/midi-forge-script` | Lua VM, `on_midi`, helpers |
| `crates/midi-forge-app/src/script.rs` | Editor / load / save / log |
| `crates/midi-forge-core/src/profile.rs` | Optional `lua` + `lua_enabled` |
| Thru path | `script.process` then `router.route` |
